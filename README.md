<h2>⭐ Featured project: <a href="https://github.com/godinhorafa/bookly">Bookly</a></h2>

<p>
  A space booking platform (meeting rooms, sports courts, event halls), built to show how I design
  software end to end.
</p>

<a href="https://github.com/godinhorafa/bookly">
  <img src="./github/bookly-dashboard.png" alt="Bookly dashboard" width="720">
</a>

<ul>
  <li><strong>Laravel API around a framework-free domain</strong>: layered architecture enforced by tests, with Strategy, Specification, Repository, Adapter and Observer where they earn their place</li>
  <li><strong>No double bookings</strong>, even under concurrent requests, thanks to a PostgreSQL exclusion constraint proven by a test that races 8 processes</li>
  <li><strong>Payments</strong> through a gateway port with Stripe and fake adapters, safe retries with idempotency keys, and unpaid bookings that expire</li>
  <li><strong>Domain events through a transactional outbox</strong> to e-mail, signed webhooks and a <strong>NestJS</strong> real-time service that updates every open calendar over WebSocket</li>
  <li><strong>React + TypeScript dashboard</strong> (Tailwind, shadcn/ui, TanStack Query) with API types generated from OpenAPI</li>
  <li><strong>Tests at every layer</strong>: unit, integration on real PostgreSQL, HTTP, contract tests, Playwright end to end, and <strong>100% mutation score</strong> on the domain</li>
  <li>10 architecture decision records, PHPStan at max level, CI on every pull request, and <code>docker compose up</code> to try it</li>
</ul>
